# Notebooks

Use notebooks for exploration and interpretation, with a clear question and stated
inputs. Name them in reading order, such as `01_explore_training_curves.ipynb`.
Import reusable logic from the installed package; avoid `sys.path` changes.

Keep committed outputs small and relevant. Large run outputs belong in
`artifacts/runs/`, and publication material belongs in `reports/`. Historical
notebooks, including their original outputs, remain unchanged in the archive.
